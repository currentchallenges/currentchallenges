# Current Challenges

Hidden Strava challenges you can join, in one list: [currentchallenges.com](https://currentchallenges.com)

Brands run dozens of Strava challenges that the app's challenge gallery doesn't show, and many come with prizes. Current Challenges keeps them in one place:

- a page for every challenge with the goal, exact dates, reward and the countries where the prize is open
- filters by sport and country
- email alerts for new challenges, no Strava account needed

Free, no ads, no login. Not affiliated with Strava.
